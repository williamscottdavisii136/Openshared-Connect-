# Phase 2B Default High-Cost Model and Mode Fact-Check Evidence Qualification

Date: 2026-07-31
Repository posture: public-safe connector/handoff record

## Purpose

This addendum records a public-interest consumer-protection R&D lane concerning whether AI agents, AI chatbots, coding agents, coding assistants, model-driven applications, and AI development tools with paid plans or usage-based billing default users into costly modes, premium models, automated model-selection modules, hosted execution, agent loops, or metered tool paths without a lowest-cost or zero-incremental-cost default being obvious to a lay user.

## Public-source fact-check status

Current public documentation supports the following general propositions:

1. Many AI agent and AI coding products use usage-based billing, credits, quotas, request meters, or token-based pricing.
2. Model choice can materially affect cost.
3. Premium, auto-select, max-context, extended-reasoning, hosted-agent, connector, plugin, cloud-execution, or background-agent modes can affect cost.
4. Some products document usage dashboards, cost tracking, alerts, model switching, or lower-cost model choices.
5. Whether a particular product defaults to the highest-cost model, highest-cost mode, or most expensive available route must be verified product by product, version by version, plan by plan, and account state by account state.

## Owner-stated R&D finding preserved

William S. Davis II states that, during R&D, the observed pattern across the target population of AI agents, AI chatbots, AI coding agents, AI coding assistants, open-source products tied to paid hosted plans, and closed-source paid products was that defaults tended toward premium, costly, hosted, or high-capability modes rather than lowest-cost, local, offline, BYOK, MCP, or zero-incremental-cost modes.

This finding is preserved as an R&D observation and audit target. It should be converted into provider-specific findings only after product-specific evidence is attached.

## Evidence required for product-specific finding

For each tested model, program, app, or AI agent, capture product/version, plan/billing state, first-run default model, default mode/module, auto-select status, whether the selected default is the highest-cost option available, whether a lower-cost lawful option exists, whether local/offline/BYOK/MCP/zero-incremental-cost routing exists, whether lower-cost routes are visible to a lay user, whether hosted/metred services run by default, whether cost warning appears before use, and whether owner approval is required before paid route escalation.

## Legal and consumer-protection boundary

This record supports public-interest consumer-protection R&D, billing-transparency research, product-specific evidence collection, owner-consent controls, price-gouging/excessive-effective-cost analysis, and agency-ready evidence classification.

This record does not assert that every provider or product has committed misconduct unless supported by product-specific evidence. It does not authorize billing circumvention, subscription circumvention, token/quota/rate-limit evasion, unauthorized credential use, session capture, certificate forgery, unauthorized third-party access, public interception, or public service exposure.
