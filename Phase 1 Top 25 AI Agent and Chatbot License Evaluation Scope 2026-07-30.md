# Phase 1 Top 25 AI Agent and Chatbot License Evaluation Scope

## Role of this public-safe connector handoff record

This record preserves the Phase 1 scope for future sessions and connector handoffs.

```text
COHORT 1: Top 25 AI agents
COHORT 2: Top 25 AI chatbots
COHORT 3: Top 25 open-source AI agents
COHORT 4: Top 25 open-source AI chatbots
```

This creates up to 100 source-tethered evaluation entries.

## Official phrase

```text
license-classified owner-authorized zero-incremental-cost R&D routing
```

## Rule

Do not treat open-source status, free pricing, local installation, or an AI-agent marketing label as blanket authorization.

Every candidate must be evaluated under its actual license, provider terms, model license, data license, API terms, account terms, marketplace terms, or owner-created local-code status.

```text
candidate list for each cohort;
source-tethered license/terms classification;
allow/review/block/unresolved status;
AI-agent interpretation notes;
zero-incremental-cost route basis;
Billy primary propagation receipt;
Williams secondary status receipt;
public-safe WAVE summary with no secrets.
```

## Guardrail

Unknown license status is not authorization.
Unknown cost is not zero cost.
Unknown entitlement is not an entitlement.
Unknown provider route is not approved.

Public repositories may carry only public-safe doctrine, routing, status, receipts, repository names, issue references, commit references, and non-secret handoff instructions.
