# Open Source License Classification Matrix Boundary

## Role of this record

This connector handoff record adds the license-classification layer to the WSD private home-network R&D zero-incremental-cost doctrine.

## Operating phrase

```text
license-classified owner-authorized zero-incremental-cost R&D routing
```

## Rule

Open-source is not a single license category. Each component must be classified by actual license or terms before it is used in the R&D zero-incremental-cost architecture.

Use exact license identifiers where known, preferably SPDX identifiers.

Examples include:

```text
MIT
Apache-2.0
BSD-2-Clause
BSD-3-Clause
ISC
Zlib
LGPL-2.1-only
LGPL-3.0-only
MPL-2.0
EPL-2.0
GPL-2.0-only
GPL-3.0-only
AGPL-3.0-only
CC0-1.0
Unlicense
BSL
SSPL
Elastic License
PolyForm
Commons Clause variants
OpenRAIL variants
Creative Commons variants
custom model licenses
custom dataset licenses
provider/platform terms
```

## Proxy-mediated R&D treatment

A component may be tested through the private home-network proxy R&D layer only when the applicable license or terms permit the relevant local, offline, mocked, simulated, sandbox, development, educational, R&D, BYOK, MCP, included-entitlement, or other no-incremental-cost route.

The proxy-mediated R&D layer may test application behavior when internet access, quota indicators, entitlement signals, billing indicators, token routes, certificate routes, provider responses, or credential routes are blocked, simulated, mocked, cached, locally returned, or routed through owner-authorized lab responses.

This is not a license override. The proxy route must be license-classified and terms-checked.

## Public-safe guardrail

This public connector record may carry license classes and non-secret doctrine only. It must not carry private credentials, private account records, private licenses, vault contents, proxy configuration, network details, tokens, certificates, private keys, cookies, private legal materials, or operational secrets.

Unknown license status is not authorization.
Unknown cost is not zero cost.
Unknown entitlement is not an entitlement.
Unknown provider route is not approved.
